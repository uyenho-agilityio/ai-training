# Resume

One topic gets one session. A new topic starts with **+ New**, so the old chat stays out of the context.

Resume opens that earlier session again. In Desktop, click its name in the sidebar. The folder stays this directory. The conversation, the files it already read, and the memory files from `/context` come back with it.

In a terminal session, `/resume` opens the same picker. From this directory, `claude --resume` opens it before a session starts.
