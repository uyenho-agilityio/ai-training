# Client Brief: Nutrition Coach

## Overall request

- Build an app named Nutrition Coach.
- The UX/UI should follow the Mijo App. It must look modern, smooth, minimal and refined.

## Core features

1. Enter personal information and calculate the daily calories and macros needed for fat loss.
2. Log the meals eaten during the day.
3. Subtract logged meals from the daily target automatically, so the user sees what is left.

## Technical requirements

- Technology: Next.js.
- Login is required. User data is stored per user on the server, not in local storage.
